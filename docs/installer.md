# Toolbag 中文补丁安装与卸载

从 1.0.0 起仅发布 Inno Setup 安装器：`dist/ToolbagChineseInstaller.exe`。旧自解压安装器及 PowerShell 安装入口已退役。

1.0.2 使用固定白色现代主题，不跟随系统切换为深色。

## 安装与更新

1. 保存工程，正常退出 Toolbag。
2. 运行安装器，选择包含 `toolbag.exe` 的程序目录。默认目录为 `C:\Program Files\Marmoset\Toolbag 5`，可以手动更改。
3. 按向导选择选项并安装。桌面和开始菜单快捷方式默认勾选。
4. 从“Toolbag 中文版”快捷方式启动。直接运行原程序不会加载补丁。

安装和卸载不依赖 PowerShell、Python 或 Qt SDK。不强行结束进程；文件被占用时请先正常退出软件。一个产品的卸载记录仅管理一个目录，迁移到其他安装目录前请先卸载原补丁。

## 文件与配置保护

运行时文件位于所选目录的 `ChineseLauncher` 下。更新前快照保存在 `.inno/backups`；用户改过的词典不会被覆盖，新默认词典另存 `.inno/defaults`。卸载成功后清理升级快照、默认副本、字体备份与安装记录，不保留补丁生成的备份文件。用户额外文件和人工修改的词典保留。已有快捷键设置功能的产品同时清理安装用户的专用配置文件；更新安装期间仍保留按键设置。

## 工程关联

关联选项默认勾选。仅接管已验证的官方打开命令，保留原参数和注册表值类型，不更改受保护的 `UserChoice`。因此不是强制设置默认应用；如果当前选择其他程序，双击工程不保证进入汉化。找不到安全的处理器时取消此选项，仍可通过快捷方式启动。

卸载只恢复仍属于补丁的命令，不覆盖用户后来作出的更改。旧版备份损坏会阻止不安全恢复；旧 ProgID 可能仍被 Windows 引用，因此迁移后可保留并指向官方程序，旧备份也会保留。

## Toolbag 字体适配

仍替换 `data/gui/font` 中已有的 `notosans_chinese.slug`、`segoeui.slug`、`selawik.slug`。先完整备份并记录哈希，再通过同目录临时文件替换。重复安装保留首次备份；卸载仅恢复仍等于补丁哈希的字体，外部修改过的字体不覆盖。旧版 `.ChineseLocalizer.backup` 在验证后迁移，恢复成功后删除哈希匹配的旧版备份和新恢复快照。缺失或可疑的旧备份会阻止替换。

## 卸载

保存工程并退出软件，在 Windows“设置 → 应用 → 已安装的应用”中找到“Toolbag 中文补丁”，选择“卸载”。不要使用旧安装器卸载，也不要手动删除 `ChineseLauncher` 后再尝试恢复关联或字体。

卸载仅移除补丁拥有的文件和快捷方式，不卸载宿主、不删除工程。仅有人工修改的词典或额外用户文件时，`ChineseLauncher` 才可能保留；补丁生成的备份目录会清除。清理失败应解除占用后重试卸载，不要手动删除尚需恢复的备份。

## 构建

```bat
source\build.bat
rem 仅打包已编译运行时：
source\build_inno.bat --package-only
```

开发机需要 VS 2022 C++ 工具链及 Inno Setup 7.1；Qt 产品还需要对应 SDK。可用 `INNO_ISCC` 指定编译器。`source/inno/product.json` 是产品清单，安装器只打包列明的文件。仓库中的安装源码自包含，不依赖其他汉化仓库；开发工具及许可证需另行准备。

当前已做独立快捷键窗口及隔离安装测试；未替用户执行真实软件的安装、卸载或工程双击验收。不要将编译或假宿主测试视为全部软件版本已经实测。

## 旧关联备份缺失的恢复

旧版 `FileAssociationBackup` 完全不存在时，只有旧安装路径、当前代理命令、机器级 `.tbscene` 官方关联和有效的同目录 `toolbag.exe` 全部匹配，才允许迁移。卸载恢复到这个已经验证的官方程序，并保留后来的外部改动；这不是还原无法获知的历史自定义命令。部分损坏的备份、其他目录或非官方目标仍拒绝操作。取消新关联选项也不会遗留旧代理指向已删除的启动器。
