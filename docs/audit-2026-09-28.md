## 修复与保留

- 严格、事务式解析 UTF-8 JSON，替换会接受截断、重复键、无效转义的旧手写扫描器。支持多行、合法代理项、占位符和全部现有词条；损坏文件不部分生效，内嵌 NUL 与超过 64 MiB 输入拒绝。
- 保留两个字体编译 Hook、字体测宽 Hook、字符限制/单行参数、前后空白缓存与原始宿主字符串。无改名、模型或场景写入逻辑。
- 修正署名窗口高度：旧代码将 DWM 枚举 33（Windows SDK 明确为窗口圆角偏好）误当标题栏高度；现按窗口 DPI 获取标题栏指标。安装最低系统与现有 DPI API 一致：Windows 10 1607。
- 删除从不读取的 TitleBarSnapshot、写入它的内联 Hook 与三类 RTTI 扫描。全源引用检索仅有定义/写入，无消费路径；删除后接口测试和完整编译通过。实际署名窗口绘制/定位仍保留。
- 修复启动器对 LoadLibraryW 转发导出的所属模块计算；给运行时 Hook 保持模块引用；补齐 trampoline 指令缓存刷新和异常隔离。
- 清理当前产品永远不会调用的 Mari/Qt 安装适配函数、未使用的 LauncherCommand/AssocId，关联代码内部命名改为 ToolbagProxy，现有注册表日志路径不变。
- 保留已有安装器保护：自定义词典、设置和额外文件不覆盖；旧版递归卸载日志替换；字体原件备份、哈希校验和外部改动保留。
